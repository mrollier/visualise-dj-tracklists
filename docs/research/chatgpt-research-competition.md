# Competitive Landscape for DJ Library Visualization & Set Planning

Below is a survey of known DJ tools and software that offer any combination of harmonic‐mixing (Camelot‐wheel) key analysis, BPM analysis, genre tagging, or graph/network visualization of a music library or set.  We cover dedicated harmonic-mixing tools, library graph tools, set-planning and auto-mix features, and built-in features of major DJ platforms. For each, we note platform, pricing, core purpose, and which features it supports (key/BPM/genre/graph, set-as-path, suggestion engine, imports/exports, local vs. cloud, and activity status).

- **Mixed In Key** (Mixed In Key LLC) – Desktop (Win/Mac); Paid. Core: Key and BPM analysis for tracks (foundational harmonic-mixing tool).  It detects keys in Camelot format and BPM, tags tracks, but has no visualizer beyond listing keys.  (No graph/network view; no set-as-path visualization; no track-suggestion engine beyond improved key detection.) It integrates with DJ libraries (via file tags) and supports “Vinyl Mode” (Key Lock without pitch change).  Mixed In Key Pro adds features like “Mashup suggestions” and transitions ideas, but still no graph view.  Mixed In Key Live (desktop) also provides real-time key/BPM detection from live audio.  **Keys/BPM:** Yes. **Genre:** No (except manual tags). **Graph:** No. **Tracklist Path:** No. **Suggestions:** Limited (Pro helps find mashups based on harmony). **Import/Export:** Reads music files; tags work in Rekordbox/others. **Local:** Yes (no cloud required). **Status:** Active. 

- **DJ.Studio** (Mixed In Key) – Desktop (Win/Mac); Paid. Core: Timeline-based DAW for DJs, focusing on mix preparation and export.  It analyzes crates and suggests track order by harmonic and BPM compatibility. Tracks are arranged on a timeline. It supports import from Rekordbox/Serato via XML and export back. Unlike our focus, DJ.Studio is linear/timeline-driven rather than graph-based.  **Keys/BPM:** Yes (analyzes BPM, key, “Harmonize” scores). **Genre:** Likely supports tags. **Graph:** No (timeline view only). **Tracklist Path:** Not visualized as path, but set is on timeline. **Suggestions:** Yes – “Harmonize” suggests next tracks to fill BPM/harmony gaps. **Import/Export:** Rekordbox, etc. **Local:** Yes (no cloud). **Status:** Active (updated into 2026).

- **Mixlog** (Ita Vero BV) – Web app/cloud; Free (alpha/beta). Core: “DJ combo assistant” – logs successful track transitions (“combos”) and uses them plus a theory-based engine to suggest next tracks. It syncs with DJ libraries (Rekordbox, Spotify, Traktor, Discogs) and provides a “set builder” and track suggestions. **Keys/BPM:** Implicit (if Rekordbox import). **Genre:** Unclear (possibly uses tags). **Graph:** No obvious graph view; UI seems list-based with “combos” log. **Tracklist Path:** No (no path visualizer). **Suggestions:** Yes – “Tune Suggestions based on music theory and your preferences”. **Import/Export:** Rekordbox XML, Spotify, Traktor, etc (cloud sync). **Local:** Cloud (requires account). **Status:** Active in beta (2024–26).

- **Mixgraph** (Nathan Cope) – iOS (iPhone/iPad); Free (with Pro unlock). Core: DJ set planner and tracker. It **scores transition compatibility** (harmony, BPM, energy, groove, mood, vocals) and lets you build sets (“flows”) with drag-and-drop, showing scores for each consecutive pair. It also has a Live mode: “identify now playing track + give next‐track suggestions”. **Keys/BPM:** Yes (Camelot key, BPM, plus proprietary “energy” metrics). **Genre:** Limited (browsable by genre) but not deep similarity. **Graph:** No; it shows linear flows with a BPM/energy curve, not an interactive network. **Tracklist Path:** Yes, the flow is a sequence (but no network visualization). **Suggestions:** Yes – AI-based suggestions for each slot, and “Listen mode” next-track recommendations. **Import/Export:** Can import Rekordbox collection; songs come from Spotify/iTunes previews. **Local:** Uses iTunes/Spotify; partly cloud for AI. **Status:** Active (App Store 2024, updated 2026).

- **DJOID Graph Playlists** (Djoid, Berlin) – Desktop (Win/Mac); Paid subscription (€99/yr). Core: Library organizer and set-builder using *graph views*. It constructs a network (“Graph”) where tracks are nodes connected by compatibility. DJs build “Graph Playlists” by adding tracks and exploring connected nodes (compatible tracks by key, energy, mood etc). Includes a “Scatter Map” (force-directed layout) and “Genre detection.” **Keys/BPM:** Yes (it analyzes BPM and keys). **Genre:** Yes – auto-detected genre/vibe for each track. **Graph:** Yes – full library visualizations (Graph Playlists and Scatter Map). **Tracklist Path:** Yes – Graph Playlist is a set path where you choose a direction and graph suggests next tracks. **Suggestions:** Yes – “Matching Tracks” finds compatible tracks in the graph. **Import/Export:** Imports from Rekordbox, Traktor, Serato, Apple Music; exports back to those and VirtualDJ. **Local:** Fully local (no cloud; 10k track limit until mid-2025). **Status:** Active (beta in 2023–26).

- **Vibes** (Ben/Matthew Taylor) – Desktop (Win/Mac); Paid (one-time ~$19) with free trial. Core: Library manager with **“Visual Set Builder”**. DJs tag tracks with “vibes” (mood/energy labels) and can arrange tracks on a canvas with connecting arrows. It has “Find Compatible” to highlight all tracks mixing-compatible with a given one. Key analysis is by neural network, BPM detection on import. **Keys/BPM:** Yes. **Genre:** Uses custom tags (“vibes”) and genre tags. **Graph:** Kind of – Visual Set Builder is a spatial layout (though not force-directed network). **Tracklist Path:** Yes – playlists built as linked chains on canvas. **Suggestions:** Yes – “Recommendations by BPM, key, vibe” and auto-suggest for set building. **Import/Export:** Reads DJ library (Rekordbox, Serato, etc) and writes back (literally writes into Pioneer/VinylDB). **Local:** Yes (offline-first; one-time license). **Status:** Active (launched ~2024).

- **Lexicon DJ** – Desktop (Win/Mac) with mobile companion; Free (generation 1) / Paid (v2). Core: Robust library management and conversion. Syncs libraries between Rekordbox, Serato, Traktor, VirtualDJ, Engine, djay, with playlist conversion, cues, BPM/genre tagging, etc. It has some “Find Mixable Tracks” feature for suggestions and “Discover” (matches tracks from streaming lists). **Keys/BPM:** Yes (reads analyzed keys/BPM from any source). **Genre:** Yes (tags, cleanup). **Graph:** No. **Tracklist Path:** No visualizer; tracklists are lists/playlists. **Suggestions:** Limited – offers “suggest your next track to mix” by rules if library is organized. **Import/Export:** All major DJ software; also Spotify/Tidal links for discovery. **Local:** Yes (desktop sync; optional cloud backup). **Status:** Active (v2.0 launched 2024).

- **MIXO** – Web (cloud); Paid subscription. Core: Cloud library manager. Syncs multiple DJ app libraries in one “playlist”. Lets you prepare once and export (e.g. to USB for Pioneer). It focuses on metadata sync across platforms. It recently added a mobile app. It does not (yet) offer graph views or advanced mix suggestions; mostly tags and structural sync. **Keys/BPM:** Reads from source libraries. **Genre:** Yes (sync/edit). **Graph:** No. **Tracklist Path:** No. **Suggestions:** None beyond playlists. **Import/Export:** Integrates with Rekordbox, Serato, Traktor, Engine, etc. **Local:** Cloud. **Status:** Active (major DJ Tip reviews 2025).

- **Tunebat (Music Database)** – Web (www.tunebat.com); Free. Core: Searchable database (70M+ songs) of track metadata (key, BPM, etc.), with analysis tools. DJs can lookup or batch-process playlists (via Spotify API) to get keys and BPM. It has a Key&BPM Finder (upload local tracks for analysis). **Keys/BPM:** Yes (BPM & Camelot key from Spotify/analysis). **Genre:** Basic (tags available). **Graph:** No (table of tracks). **Tracklist Path:** No. **Suggestions:** Indirect – site shows “browse harmonic data and recommendations” but no direct next-track suggestion engine. **Import/Export:** Spotify playlists, or manual upload. **Local:** Web service (requires Spotify login for full DB). **Status:** Active (constant website updates).

- **VocalRemover.org Key/BPM Finder** – Web; Free. Core: In-browser analyzer for key and BPM. Serverless (client-side) so files stay local. Drops vocals or just analyzes. **Keys/BPM:** Yes (estimates musical key/scale & BPM). **Genre/Graph:** No. **Tracklist Path/Suggestions:** No. **Import/Export:** Upload local files. **Local:** Yes (client-side only). **Status:** Active.

- **Ghost Production DJ Set Planner** – Web; Free. Core: Upload a folder of tracks, then it analyzes each and **auto-orders** them for harmonic mixing. The output is a setlist ranked for Camelot-wheel compatibility, with color-coded transitions. (No interactive UI beyond list and CSV/PDF export.) It runs entirely in-browser (no server upload). **Keys/BPM:** Yes. **Genre:** No. **Graph:** No (list only). **Tracklist Path:** Yes (optimized path), but no network graphic. **Suggestions:** Implicit – it auto-builds the full set order. **Import/Export:** Imports local audio; exports CSV/PDF. **Local:** Yes (analysis done client-side). **Status:** Active (online tool).

- **Mix Maker – DJ Set Planner** (Rebels Productions) – macOS (Apple Store); Paid (~$0.89). Core: Desktop set-builder that “explores unlimited transitions” locally. You import your library (can import Rekordbox DB) and it pre-calculates mix preview between tracks. It shows track adjacency/compatibility so you can quickly shuffle playlists. Works entirely offline. **Keys/BPM:** Yes. **Genre:** Likely via tags. **Graph:** No UI graph; uses drag/drop list. **Tracklist Path:** Yes, you build a sequence but not on a graph. **Suggestions:** Yes – it “suggests compatible tracks” and previews transitions instantly. **Import/Export:** Rekordbox (reads collection, cue points), exports to Rekordbox/Serato/Traktor/Virtual DJ/djay. **Local:** Yes (offline). **Status:** Active (v2.0 in 2025).

- **VirtualDJ** (Atomix Productions) – Desktop (Win/Mac); Free (home) or Paid (Pro licensing). Core: General DJ software. Supports key/BPM analysis and displays a harmonic mixing indicator (pad color under track to mark compatible keys). It introduced a **“Related Tracks”** feature (Early Access builds) which suggests tracks that “follow” the current track (auto-populated from a library). Also *LiveFeedback/GeniusDJ*: a crowd-based suggestion engine that shows popular next songs (from VirtualDJ users and online sources). **Keys/BPM:** Yes (analysis and UI cues). **Genre:** Tags, limited. **Graph:** No (waveforms only). **Tracklist Path:** No graph view. **Suggestions:** Yes – “Related Tracks” (BDJ’s solution, essentially like Rekordbox’s feature) and GeniusDJ/LiveFeedback for recommendations. **Import/Export:** Built-in library or external playlists. **Local:** Yes (desktop, but suggestions use online data). **Status:** Active (feature in beta as of 2024).

- **Rekordbox** (Pioneer DJ) – Desktop (Win/Mac); Free (Core) or Paid (Creative subscription). Core: Standard DJ library manager for Pioneer gear. It **analyzes** BPM and Key (Camelot notation) on import. It offers **Related Tracks / Track Suggestion** features: DJs can filter library by criteria (key, BPM, genre, artist, etc.) to suggest compatible next tunes. There are built-in modes like “BPM+KEY” or “Era/Mood” to fine-tune suggestions. **Keys/BPM:** Yes. **Genre:** Yes (tags, plus Mood features). **Graph:** No (linear browser). **Tracklist Path:** No. **Suggestions:** Yes – Related Tracks panel and Track Suggestion modes give next-track lists. **Import/Export:** Core library; exports USBs for CDJs. **Local:** Yes. **Status:** Active and industry-standard.

- **Serato DJ Pro** (Serato) – Desktop (Win/Mac); Paid. Core: DJ performance software. It analyzes BPM and Key. It has a **“Relative Pitch”** feature for vinyl-mode harmonic mixing (keeps musical key when changing pitch). It does *not* have a built-in “related tracks” panel (unlike Rekordbox). **Keys/BPM:** Yes. **Genre:** Tags (manual). **Graph:** No. **Tracklist Path:** No. **Suggestions:** Limited – no built-in suggestions (some streaming-only automix features like Pyro on iOS). **Import/Export:** iTunes, iTunes Store tracks; crate playlists. **Local:** Yes (plus optional SoundCloud/Beatport streaming integration). **Status:** Active.

- **Traktor Pro** (Native Instruments) – Desktop (Win/Mac); Paid. Core: DJ performance software. It analyzes BPM and key (Open Key). It has advanced cue/loop functions and dynamic playlist sorting, but no dedicated “related track” feature. DJs can sort by key or BPM to find mixes. **Keys/BPM:** Yes. **Genre:** Tags. **Graph:** No. **Tracklist Path:** No. **Suggestions:** Limited – no native recommendation engine (aside from user-sorted lists and sample deck auto loop transitions). **Import/Export:** Internal library, no direct linking to CDJs. **Local:** Yes. **Status:** Active.

- **Engine DJ** (Denon DJ) – Desktop (Win/Mac); Free. Core: Library software for Denon’s hardware. Similar to Rekordbox; analyzes key/BPM. Has “Fuse” streaming plus playlist features, but no advanced suggestion engine announced. Likely has related-track functionality similar to Rekordbox (Engine OS borrowed many features). **Keys/BPM:** Yes. **Genre:** Tags. **Graph:** No. **Tracklist Path:** No. **Suggestions:** Basic – “Just Play” autoplay based on BPM/genre, no visible graph or path. **Import/Export:** Rekordbox DB, Serato XML. **Local:** Yes (plus cloud for streaming search). **Status:** Active.

- **Algoriddim djay Pro AI** – Desktop/Mobile (macOS, iOS, Android, Windows); Freemium (Pro features). Core: DJ app with deep streaming integration. Key/BPM analysis, library search. Features: **Match** (using streaming services’ recommendations for next track) and **Automix AI** (full AI-driven continuous mixes). Essentially it suggests tracks based on TIDAL/Spotify algorithms. Also has optional AI “co-pilots.” **Keys/BPM:** Yes. **Genre:** Via tags or streaming metadata. **Graph:** No. **Tracklist Path:** No. **Suggestions:** Yes – Match suggests next tracks (streaming-based). **Import/Export:** iTunes/Music library integration; works best with streaming (Pandora, TIDAL). **Local:** Both (offline library mode) but best with cloud. **Status:** Active.

- **PulseDJ** – Web/mobile; Paid (subscription for data). Core: Companion AI tool. It does *not* play music but interfaces with other DJ software to suggest tracks. It uses aggregated data from many DJs’ sets (social data) to recommend what tracks are commonly played before/after the current one. **Keys/BPM:** Not by analysis – purely co-play data. **Genre:** Can filter by genre/scene. **Graph:** No UI beyond list of suggestions. **Tracklist Path:** No. **Suggestions:** Yes – next-track suggestions based on crowd-sourced patterns. **Import/Export:** Connects via plugin/APIs. **Local:** Cloud (requires internet). **Status:** Active.

- **Academic/Hobbyist Projects:** Several research and open-source efforts have visualized music collections as graphs. For example, Muelder *et al.* (2011) proposed a graph interface where each song is a node linked by audio-content similarity. Similarly, **Music-Graph** (open source by regorxxx) provides a genre/style network (to compute similarity between sets of tags). **GraphMyTunes** (Elliot Jordan, 2025) is a Python tool that parses an iTunes/Apple Music XML and generates charts (histograms of BPMs, ratings, decades, etc.); while not interactive or DJ-specific, it shows library distributions.  These tend to be one-offs (e.g. **GraphMyTunes** is free on GitHub) and emphasize analysis graphs, not Camelot wheels or interactive paths.  **Keys/BPM:** Some (GraphMyTunes shows BPM stats). **Genre:** Often only high-level or via tags. **Graph:** In concept (e.g. Music-Graph mapping genres) but not mainstream tools.  **Tracklist Path/Suggestions:** No.  **Local:** Yes (scripts).  **Status:** Experimental/abandoned.

- **Miscellaneous:** Some smaller or older utilities exist. For example, a free “Harmonic DJ Set Planner” (like Ghost above) on TheGhostProduction or browser extensions that add sort-by-key to Spotify. Streaming tools (e.g. TuneBat above, or KeyFinder.com) extract audio features but seldom integrate DJ logic.  Most major streaming or library apps **lack** a true graph or path view, leaving that space largely unfilled by active products.

## Where Our App Overlaps

Many features of *visualise-dj-tracklists* have analogs in existing tools. In particular, **harmonic/Camelot key and BPM analysis** are staples: Mixed In Key, Rekordbox, VirtualDJ, djay Pro, etc., all compute and display keys. Most set-planning tools (Mixgraph, DJ.Studio, Mixlog, Mix Maker, DJOID) support BPM and key matching in one way or another. Our *suggestion engine* overlaps with features like Rekordbox’s Related Tracks (key/BPM filtering), Algoriddim’s Match (AI recommendations), and VirtualDJ’s LiveFeedback/GeniusDJ (crowd-sourced suggestions). The concept of plotting a whole library spatially is similar to DJOID’s Graph and Vibes’ Visual Builder (though those use their own metrics). Finally, a local-first focus is somewhat rare but notable; Vibes and Mix Maker also emphasize offline/local operation, and DJOID is local-only.

## Gaps and Differentiators

However, **our approach has several unique angles**. Very few tools combine a **full library network on a Camelot wheel** with live set-path overlays. DJOID and Vibes have visual layouts, but not specifically on the Camelot circle. Our “tracklist as a graph walk on the wheel” appears unmatched: existing graph tools either use force-directed maps (DJOID, GraphMyTunes) or flat lists, not the specialized wheel layout. Our multi-method genre similarity (from exact tags to co-occurrence embeddings) is also novel: only the open-source Music-Graph and industry systems (like Shazam’s internal models) touch on genre networks. “Vinyl mode” strict pitch-shift matching (only mixing tracks without changing key) is supported by Serato’s Relative Pitch and by DJOID’s harmonic rules, but integrating this choice into suggestions is rare. The fully client-side, account-free design likewise is unusual among recommendation tools (almost all including Mixlog, PulseDJ, Mixgraph rely on cloud data or AI services). In summary, *visualise-dj-tracklists* overlaps with others on analysis (key/BPM) and suggestions, but its **graphical style and multi-faceted genre logic** are fresh.

**Tools to investigate further:** DJOID and Vibes deserve a close look for their UI and set-builder concepts. Also check the GhostProduction set planner and Mix Maker for their pure set-reordering logic (they provide useful UX ideas). Mixed In Key’s ecosystem (especially DJ.Studio’s Harmonize engine) offers inspiration for suggestion algorithms. Finally, the Algoriddim and VirtualDJ AI features could influence our suggestion criteria design, while the Music-Graph project might inform our genre-network implementation.
